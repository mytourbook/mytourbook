New / Improvements
==================

* Tour Chart
  - Delete time slices, the tour chart is now a more functional tour editor with an undo/redo feature, before only e.g. tour markers could be modified
    https://github.com/mytourbook/mytourbook/issues/1755
  - With the key "o", move the other vertical slider to the same position as the selected vertical slider
  - New actions:
    - Move the left slider to the tour start
    - Move the right slider to the tour end
  
* Tour Segmenter
  - Display elevation gain/loss values within break times
    https://github.com/mytourbook/mytourbook/issues/1545#issuecomment-6164256356
  - When the break time segmenter is selected, the tour chart displays the updated break times
  

Changes
=======

* -vmargs
  - Command line parameters with -vmargs can cause this issue https://github.com/mytourbook/mytourbook/issues/1773 or similar issues.
    This is fixed by these new features https://github.com/mytourbook/mytourbook/issues/1773#issuecomment-6310876191

* Tour Chart
  - Toggle active vertical slider with the keyboard is now "t", before it was the "Ctrl" key
  

* Tour Editor
  - When only one time slice is selected in the tour editor, then the tour chart is positioning both vertical sliders at the same position, before there was a gap of 1 time slice
  - Changed shortcut to revert all tour modifications from Ctrl-Z to Ctrl-R, Ctrl-Z is now the undo action in the tour chart
  
    

Bugfix
======
  
* Tour Editor
  - When time slices were deleted which contained tour markers, the other tour markers positions were wrong
